   * - Question about device RF capabilities re: object 28
       * - [https://github.com/OpenMobileAlliance/OMA\_LwM2M\_for\_Developers/issues/595](https://github.com/OpenMobileAlliance/OMA\_LwM2M\_for\_Developers/issues/595)

   * - JD  Question about FOTA Pull
   * In the current LwM2M specification, the provisioning of the FOTA Pull connection on the device is not explicitly defined. In particular, there seems to be no standardized way to provision credentials specific to the FOTA Pull mechanism.
   * Is there a specific reason why credentials for FOTA Pull cannot be defined via an optional Security Object (or OSCORE Object) instance, similarly to how LwM2M Bootstrap and Management connections are provisioned?
   * This question comes up increasingly in the context of cybersecurity compliance (e.g. CRA / RED). Our customers are asking why LwM2M provides a well-defined and secure provisioning model for Bootstrap and Management, but not an equivalent, standardized mechanism for FOTA Pull.
