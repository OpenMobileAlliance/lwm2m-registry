## Northbound API update



   * - Device Group work has started
   * 

           * Add device to device group
           *  POST /deviceGroups/{ID}/memberDevices
           *  
           * Change friendly name of group
           *  POST /deviceGroups/{id}/friendlyName
           *  
           *  Create device group
           *  POST /deviceGroups
           *  
           *  Delete device group
           *  DELETE /deviceGroups/{id}
           *  
           *  List device groups
           *  GET /deviceGroups?associatedUnits.id={unitId}\&maxResults={maxResults}\&nextToken={nextToken}
           *  
           *  List devices in groups
           *  
           *  GET /deviceGroups/{id} - support paged results 
           * 

           *  Remove Device from group
           *  DELETE /deviceGroups/{id}/memberDevices/{endpointId}
           *  
           *  Create combinations of groups (US, water, gas, etc...)
           *  Adding groups to a group
           *  POST /deviceGroups/
           *  DELETE / deviceGroups/{ID}
           *         - ID removed
           *         
           * DeviceOperation based upon groups
