## IoTerop Server API 

- Two security schemes defined: ApiKeyAuth and OAuth2.
- Tags to organize the operations: Device, Device Operation, and Device Observation.

- Paths

1. `/lwm2m/v1/devices/{deviceId}`
2. `/lwm2m/v1/devices/{deviceId}/operations`
3. `/lwm2m/v1/devices/{deviceId}/operations/{operationId}`
4. `/lwm2m/v1/devices/{deviceId}/operations/{operationId}/successTargets`
5. `/lwm2m/v1/devices/{deviceId}/operations/{operationId}/errorTargets`
6. `/lwm2m/v1/devices/{deviceId}/observations`
7. `/lwm2m/v1/devices/{deviceId}/observations/{observationId}`
8. `/lwm2m/v1/devices/{deviceId}/observations/{observationId}/notifications`
9. `/lwm2m/v1/devices/{deviceId}/observations/{observationId}/notifications/{notificationId}`

- Operations

1. Start a LwM2M operation by sending a POST on the device operation API. This  returns an operation handle (i.e., "operationId": "01CD")
2. Retrieve the operation result by sending a GET on the operation handle
